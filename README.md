# 72+ 邮轮模块配置器

独立的静态三维交互原型。当前不修改或替代 https://72cruise.haoooo.workers.dev/ 。

## 使用
- 点击模块卡片添加，或拖放到墙面；墙上拖动模块可换区、调高。
- 设置中以 25 mm 为档调整中心高度，亦可使用方向键上下移动选中模块。
- 切换四个场景，或自动演示；柜门、灯、香氛、折叠台具有可操作状态。
- 右侧可查看模块原理、标准件建议与配置清单，导出 JSON；画面可导出 PNG。
- 原型数据不自动持久化，请导出配置保留修改。

## 模块与接口
平面展陈沿用 V3 夹持概念。展柜、层板与活动台需要新承力背架；灯具与香氛独立低压机芯，不通过圆导柱导电。所有新增部件是概念几何，不代表生产 CAD 或实物性能。

## 尺度
- 全部三维几何采用米，UI 标注毫米。
- 墙面 2900 × 2900 mm，四根梯柱组成三跨。
- 方形节点 48 × 48 mm；梯柱外宽22 mm、深24 mm。
- 714 mm 柱距由 700 mm 展板和两侧7 mm偏置得到，是延展装配值。
- 横档 Ø5、节距25 mm延续V3假设，未实测。
- 只校验模块墙面投影重叠；背部挂点、柜门运动、操作臂、线槽和全部三维干涉未经过工程验证。
- 不提供未经验证的承重、照度、吸声、香氛覆盖范围或船用合规结论。

## 网站接入
`dist/` 是自包含的静态页面，可作为现有项目的独立模块配置页面部署。Three.js 0.170.0 和 OrbitControls 均已随页面提供，无外部 CDN 运行依赖。`model.js` 为模块元数据、场景预设和布局约束；`app.js` 为交互和3D几何。

若在原站内嵌，需将本页发布到原站可访问的路径后再以 iframe 或独立路由接入；这里没有修改原站源码。导出 JSON 以 `type / bay / y / state` 为核心状态，保留毫米尺寸与接口说明。
