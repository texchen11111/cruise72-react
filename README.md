# 72+ 邮轮模块配置器 · 48 mm 网格

独立静态 Three.js 原型；未修改原项目 workers.dev 网站。

- 基础单元 48 × 48 × 48 mm。2900 mm 墙面内设置 60 × 60 格，四边各留10 mm；深度24格。
- 位置 `gx,gy,gz` 是包络左下后角的整数格坐标，相对网格原点。拖动在 XY 平面吸附，右侧输入或方向键 / PageUp / PageDown 每次移动一格。
- 9 类模块均以整数格包络占位，实际板材与零件不必48 mm厚。基础方块为1格立方体。
- 三维整数 AABB 检查禁止占位重叠，允许相邻接触。展柜开启额外预留14格前方空间，活动台始终保留14×10×10格折叠包络。
- 四种活动预设、颜色、灯光、香氛、柜门、折叠台、清单与JSON/PNG导出。
- 数据不自动持久化，修改后请导出JSON。

## 工程边界
网格不是原梯柱孔距。原714 mm柱距及假定25 mm横档节距不能直接对应48 mm；画面适配层是新设计示意，仍需二次框架/背板连接真实梯柱。离墙叠放允许空间探索，但连接、支撑及承载未验证。V3内部机构不能由占位模型直接生成生产件。
预留空间检查不替代真实精细模型的运动、干涉、承载或船用验证。

## 文件
`dist/model.js`：元数据与网格规则；`dist/app.js`：交互和3D几何。`dist/vendor/`：Three.js 0.170.0及OrbitControls，本地提供，无运行时CDN。
导出数据含 `grid.unit_mm/counts/origin_wall_mm`、模块 `position_cells / size_cells / reserved_cells`，可供后续CAD及网站接入。

## 验证
`node tests/grid.mjs` 检查四个预设、状态切换、三轴48 mm位移、邻接/重叠、深度分层、边界与添加空位。另执行JS语法检查；本次未运行浏览器端QA。
