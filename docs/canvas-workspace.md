# 画面优先的配置器界面

2026-09-30 的界面更新基于机械修复提交 `514db22`，只修改 React 界面和样式。

## 使用方式

- 中央画面占满页头下方的可用区域。打开侧边面板不会改变画面尺寸或重置视角。
- 左侧「模块」「场景」「说明」和右侧「设置」默认收起。鼠标悬停或键盘聚焦可以展开，移开后延迟收起。
- 点击入口会固定面板；可点击「已固定」取消固定，或点击 ×、按 Esc 收起。输入框编辑时不会因为鼠标离开而收起。
- 手机通过点击入口展开，同样可以使用右上角导出。
- 「设置」内继续提供模块设置与配置清单；分类和预设场景相互独立。
- 右上角「场景效果图」按需打开叠加图册，提供四张已有概念图、前后切换和缩略图选择。左右方向键切图，Esc 返回。查看图片不会切换预设、改变构件或重置相机。

## 维护入口

| 文件 | 负责内容 |
| --- | --- |
| `src/App.jsx` | 页头、浮动入口和界面状态；保留原导出和 `window.__planner` 接口 |
| `src/components/HoverPanel.jsx` | 悬停、聚焦、固定、关闭和延迟收起 |
| `src/components/Stage.jsx` | 持续挂载的画面、视图按钮、截图、提示；保留 `window.__plannerCamera` |
| `src/components/ScenePicker.jsx` | 从原 Stage 提取的预设和展陈选择，不改变预设数据或调用方式 |
| `src/components/RenderOverlay.jsx` | 效果图叠加层；图片继续使用 `public/scenes/` |
| `src/styles/workspace.css` | 以 `.canvas-app` 为范围的工作区布局，以及浮层、图册样式 |
| `tests/react.mjs` | 原交互测试，加面板显隐、效果图切换及渲染器不重建检查 |

## 与 Kimi 的合并边界

本轮不修改 `src/model/`、`src/store/`、`src/scene/`、Rhino 模型资产或 Inspector 的机械字段。
机械尺寸、夹持、节点挂接和梯柱分段的剩余问题仍由模型任务处理，界面更新不代表这些问题已经解决。
不要用整目录覆盖的方式合并；按提交合并并重新构建。`dist/` 是构建输出，冲突时从合并后的源码重新生成。
