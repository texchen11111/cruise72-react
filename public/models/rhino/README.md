# Rhino V3 模型资料

这里集中放 Rhino 模型的网页资料和导出说明。原始文件是本机的 `墙1111111111.3dm`，没有把 11 MB 的源文件复制进网站；这样网页仓库保持轻量，同时不会误把网页近似几何当成加工文件。

`spec.json` 记录了原文件单位、建模容差、节点包络、9 mm 窄颈、Ø6 × 30 mm 圆导柱、6 mm 夹持板和关键对象名称。网页中的 `V3 梯柱段` 与 `48 mm 基础节点` 使用同一组约束，方便布局、拖动和导出时追溯。

要更新 Rhino 尺寸：先在原始 `.3dm` 中完成测量和干涉校核，再更新 `spec.json` 与 `src/scene/models/rhino.js`，最后运行 `npm test` 和 `npm run build`。网页几何用于交互原型，不能代替加工图、连接强度或现场安装验证。
